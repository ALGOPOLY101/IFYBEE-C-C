GIT IS A VERSION CONTROL SYSTEM

IT HELPS THE DEVELOPER TRACK CHANGES TO THIER CODE OVERTIME
GIT HELPS US TO SOLVE THE PROBLEM OF HAVING MULTIPLE FILES OR LOOSING OUR FILES BY ALLOWING US TO SAVE DIFFERENT VERSIONS OF OUR PROJECTS.


VERSIONCONTROL GENERALLY MEANS KEEPING TRACK OF CHANGES MADE ON FILES OVER TIME

GITHUB- is an online platform where git repositories can be the stored


GIT IS THE TOOL THAT TRACKS YOUR CODE WHILE GIT HUB IS THE PLATFORM THAT WE USE TO STORE AND SHARE THE CODE
